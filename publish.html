Publish Penumbra

Everything for Figma's publish form, ready to copy. Publishing only works in the Figma desktop app.

1Try it once in Figma desktop

Review rejects plugins that crash, and Penumbra has only run in a browser so far. Plugins → Development → Import plugin from manifest…, then in the file picker press ⌘⇧G and paste:

Manifest

If Figma rejects the id: Plugins → Development → New plugin…, copy the id it generates into manifest.json, delete the folder it made, import again.

2Describe it

Plugins → Manage plugins… → Penumbra → Publish. The name and tagline carry the words people search for ("shadow", "drop shadow", "realistic shadow"), so keep them as they are.

5Data security form

Optional; Flow to Lottie has one. Paste whichever answer the question asks for.

Network
None. The plugin makes no network requests; its manifest allows no domains.
Data collected
None. No accounts, analytics, tracking or third parties.
Data stored
Each shadow's settings in shared plugin data on its layer, inside the file. The last-used shadow in figma.clientStorage, on the user's device.
What it changes
Only the selected layers' drop shadows, and the shadow layers it groups with them.
